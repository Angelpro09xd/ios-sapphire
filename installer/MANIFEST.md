# What the installer reproduces

Inventory of 2026-11-08: the phone's iOS root (read from Android through the dual-boot app's HFS+ reader,
`android/dualboot/test/HfsWalk.java`, 386 710 entries) against the image first flashed
(`~/ios-build/ios16-root.img`, 334 254 entries; built by `tools/mkiosroot.sh`, finished by
`~/ios-build/finish-root.sh` + `tools/sweet-root-tweaks.py`). `tools/inventory/diff.py` makes the lists.
Result: 65 230 entries added, 8 339 changed, 12 773 removed. What the installer must reproduce falls in
four parts; what is personal is never packaged.

## 1. Ours (in the GitHub release)
- `/redwood` (118 MB): the GL bridge (libredwood-gl, glload), Mesa (libOSMesa), the telephony / Bluetooth /
  camera / sensor bridges, `/redwood/bin` daemons (fpd, vibd, bbstart, ...), tuning files.
- Our apps in `/Applications`: Android.app (dual boot), Reproductor, GLSpin; Huella (fingerprint) as IPA.
- Our tweaks in `/var/jb/usr/lib/TweakInject`: SapphireDisplayLink, SapphireFingerprint(+Settings),
  SapphireButtonRegenerator, ... (not SapphireSampler: a profiler).
- Useful tools from `/var/root` (curated; not the experiments): hidtouch, machnow, cpuload, hfsgrow, hfsshrink,
  qmitool, camdump/rawtool, fpload/fpsave (the tools, not the data), code/unlock helpers.
- Xiaomi firmware the iOS side loads (GPU a610 zap/sqe, sensors `sensfiles`, Bluetooth `btfw`, audio `*.arp`):
  firmware may be redistributed, as AOSP ROMs do.

## 2. Jailbreak packages (installed by apt on first boot, from the same repos)
Repos: apt.procurs.us (iphoneos-arm64-rootless/1800), havoc.app, repo.chariz.com, apt.thebigboss.org,
sparkdev.me, repo.getsileo.app. Packages added after the base image:
com.ali.aim, com.alphastream.linearforsb, com.fiore.calculatorconverter, com.ichitaso.iconorder,
com.nightwind.boldersreborn, com.opa334.trollstorehelper, com.ryannair05.cylinder, com.serena.appindex,
com.spark.libsparkcolourpicker, com.spark.snowboard, com.spark.snowboard.statusbar,
com.spark.snowboardapplication, com.sreerag.duofree, com.tigisoftware.filza, ellekit, preferenceloader,
org.coolstar.sileo, xyz.willy.zebra, ws.hbang.alderis, ws.hbang.common, gawk, gzip, htop, nano, neofetch,
oslog, p7zip, unrar, unzip, zip. (gsc.* / cy+* are dpkg's virtual firmware packages.) Removed since:
libdimentio0, libkrw0, shshd. Themes/settings of Cylinder and SnowBoard: copied as user data only if the user
chooses to (they live in /var/jb/Library/{Cylinder,Themes,SnowBoard} and preferences).

## 3. Recipes applied to the user's own IPSW (Apple files are never redistributed)
- `Info.plist` of ~190 apps: `CADisableMinimumFrameDurationOnPhone` = true (120 Hz animations).
- System apps copied from the AppOS cryptex into `/Applications` (`tools/sapphire-apps-gl.sh`), their
  `/System/Library/AppPlaceholders/*` removed.
- launchd's job cache `/System/Library/xpc/launchd.plist`: our jobs added (glload, fpd, vibd, arplay,
  sensord, camd, btshim, bbstart, files, wifidkick, ...), the disabled ones removed (dasd, coreduetd,
  aggregated, wifip2pd) -- one recipe per job, each from its plist in the repo.
- `/bin/sh`, `/bin/bash`: the jailbreak's bash instead of the symlinks.
- `LocalStorageFileProvider.appex`: replaced by a 67 KB stub -- TO CHECK what and why.
- Six wallpapers 644 -> 755; audio HAL plug-ins moved aside (`/Library/Audio/Plug-Ins/HAL.disabled`).
- Everything `finish-root.sh` and `sweet-root-tweaks.py` do (logd stores, plain system keybag, ...).
- NOT changes (artifacts of the comparison): the dyld shared caches / cryptex files are hard links (the
  reader shows the link's mode), ~200 WorkflowKit names differ only in Unicode normalisation.

## 4. Personal: never packaged
App data and the user's apps (`/private/var/containers`, `/private/var/mobile/Containers`), photos/media,
messages, keychain and keybags, `/private/var/wireless` (the SIM's CommCenter state: ICCID, IMSI, number,
carrier bundle cache, usage databases -- regenerated by iOS from the SIM; SIM *support* is part 1), Wi-Fi
preferences, system databases and logs, `/var/root/cam` (camera dumps) and **`/var/root/fp` (fingerprint
templates and calibration: biometric data)**.
